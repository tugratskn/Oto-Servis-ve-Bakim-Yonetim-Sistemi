# Oto-Servis-ve-Bakim-Yonetim-Sistemi

## 📌 Projenin Amacı
Oto servislerindeki araç kabul, arıza teşhis, usta işçiliği ve yedek parça süreçlerini tek bir merkezde toplayan operasyonel bir altyapıdır. Sistem; araç sahibini, servis danışmanını ve atölye teknisyenlerini kopuk süreçlerden kurtarıp aynı veritabanında buluşturur.
